# 变钟法换位谱验真台

一个**纯前端**的变钟法（Change Ringing）换位谱真伪验真台。领钟员在上钟前输入起始排列、
记谱与计划重复轮数，应用逐轮逐换位生成钟位行，并对整段乐段给出可逐行复核的结论。
所有计算都在浏览器内完成，不向任何服务端发送数据。

## 判定规则

记谱由一串 **token** 组成，token 之间以空格分隔：

- `x`：所有相邻位置两两交换（即不留任何置位号），**仅在偶数钟时成立**；
- 位置号（如 `14`、`123`）：由 `1` 至 `N` 的数字直接拼成，**严格递增且不重复**，
  对应位置上的钟保持不动；
- 其余每个**连续未置位区段必须为偶数长度**，区段内的钟从左到右两两交换。
  任何奇数长度的孤立未置位区段都会使该 token 非法（配对错误）。
  - 例：四口钟上 `1` 留下位置 2–4 的长度 3 区段 → 非法；
  - 例：四口钟上 `2` 留下位置 1 的长度 1 区段 → 非法。

整段计划是“整列 token 按计划重复轮数反复执行”。**重复轮数含首轮**，
即 `轮数 = 2` 表示整列 token 总共执行两遍。

判定结论有三种：

| 结论 | 条件 |
| --- | --- |
| **真 · 闭合**（closed） | 计划终点**首次**回到起始行，且此前没有任何重复行 |
| **假**（false） | 计划执行中出现任何重复行，包括**提前回到起始行**（计划长度因此失效） |
| **未闭合**（open） | 全程没有重复行，但计划终点不是起始行 |

界面会：

- 在记谱处就地标记每个非法 token，并区分**语法错误**（字符、越界、重复、非递增）
  与**配对错误**（奇数钟用 `x`、奇数长度未置位区段）；
- 展示完整逐行轨迹（序号、轮次、轮内第几个换位、token、钟位行）；
- 对重复情况给出**首次冲突的两处位置**（精确到轮次与轮内换位序号）及对应的同一排列，
  并高亮轨迹中的两行；
- 长乐段轨迹**完整保留、分页浏览**（每页 500 行，表格上下各有一组分页器，
  支持首页/上一页/下一页/末页与页码跳转，以及到起始行、冲突两处和终点的快捷跳转），
  保证最终行与每一行都可逐行复核；执行上限为 100 万个换位。

## 本地开发

依赖 Node 20+：

```bash
npm ci
npm run dev        # 本地开发服务器
npm run test:ci    # 运行自动化测试（Vitest，单次模式）
npm run build      # 生产构建，产物在 dist/
npm run preview    # 本地预览生产构建
```

## 用 Docker Compose 启动

启动常驻 Web 服务（构建后以 nginx 提供静态页面）：

```bash
docker compose up web --build
# 打开 http://localhost:8080
```

宿主端口由 `WEB_PORT` 控制，默认 `8080`，可直接覆盖：

```bash
WEB_PORT=9000 docker compose up web --build
# 或复制 .env.example 为 .env 后修改
```

### 一次性验收服务 `verify`

`verify` 服务在干净的构建容器中运行**自动化测试与生产构建**，随后退出；
退出码 0 即验收通过：

```bash
docker compose build verify
docker compose run --rm verify
```

## 项目结构

```
index.html                 单页界面
src/main.js                界面装配、输入校验定位、轨迹与冲突渲染
src/style.css              样式
src/core/verifier.js       纯函数核心：token 校验、排列解析、计划执行与判定
src/core/verifier.test.js  核心逻辑自动化测试
src/ui.smoke.test.js       基于 jsdom 的真实界面装配冒烟测试
Dockerfile                 多阶段：builder（Node 测试/构建）→ web（nginx 静态服务）
docker-compose.yml         web 常驻服务 + verify 一次性验收服务
```

## 自动化测试覆盖

`src/core/verifier.test.js` 覆盖题目要求的全部情形：

1. **合法闭合**：Plain Bob Minimus 完整长记谱（8 个 token × 3 轮 = 24 个换位），
   全程无重复且终点首次回到 `1234`；
2. **奇数钟 x**：五口钟上 `x` 报 `odd-x`；
3. **孤立未置位区段**：四口钟 `1`（区段 2–4 长度 3）、`2`（区段 1 长度 1），
   六口钟 `3`（区段 4–6 长度 3）；
4. **跨轮重复**：四口钟 `x 12 x` 执行两轮，排列 `2134` 分别出现在
   第 1 轮第 2 个换位与第 2 轮第 1 个换位之后；
5. **提前闭合**：`x 14` 的轨道周期为 8 步，计划 5 轮（10 步）时起始行在第 8 步
   提前出现，判假；
6. **未闭合**：`x 12 x` 执行一轮，无重复但终点是 `1243`。

此外还包含 token 语法、起始排列解析、轮数解析、轨迹偏移定位等边界测试，
以及基于 jsdom 的界面冒烟测试（真实装配 `index.html`，模拟点击验真，
覆盖闭合、跨轮冲突高亮、提前闭合、未闭合、错误定位，以及长乐段分页下
每一行与最终行均可翻页/快捷跳转复核），共 32 项。
